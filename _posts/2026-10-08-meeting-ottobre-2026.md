### Your coding agent is a while loop!

Questo meetup del JUG Torino si terrà online, in streaming su YouTube.

#### Session Abstract

Most of us let an agent write our code every day, but almost none of us have ever opened one.
So we guess what is inside: a planner, an orchestrator, a state machine, something very clever...

There is nothing clever in there. There is a loop. A very simple one, also.

I will build a coding agent on stage, in plain Java, from an empty file. No frameworks, just plain code.
It runs against a model on my laptop through Ollama (a system to run LLMs locally).
So there is no API key and no bill, and nothing on stage breaks when the conference wifi does :)

There is instead a while loop, about fourteen lines of Java, and a few functions you could have written on your first day at work.
Everything else is there to protect from the stupidity of the model. Yes, the loop and the model are stupid, and the harness is mostly an armour.

**What you will see**

1. A Java coding agent (I wrote) that already works. I ask it for a new HTTP endpoint and you watch it ship one.
   ...and then we start coding from scratch
2. Why a chatbot cannot touch your code, and the fourteen lines of Java that change that.
3. How it decides what to do next, when there is no plan anywhere in the code.
4. What happens the first time you let it write to your disk.
5. What stops it when the model gets it wrong: broken tool calls, an edit that fits in two places, a loop that never ends, and a file it should not open.
6. Why agents feel slow and cost what they cost. One number answers all three.

A total of nine live demos, every one offline, every one from a git tag you can check out yourself.

Hey, remember this: you will not leave with a framework to adopt.

You will leave knowing exactly how the thing on your machine works, and quietly certain that you could have built it yourself!
